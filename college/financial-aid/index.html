💵 Financial Aid & the FAFSA, Explained

How college financial aid works: the FAFSA, the Student Aid Index, grants, scholarships, work-study, loans, the CSS Profile and comparing aid offers.

📅 Updated October 2026✍️ High.School Editorial Team✅ Editorial policy

The sticker price of college is rarely what families actually pay. Grants, scholarships and other aid can cut the cost dramatically — but only if you apply. The single most important step is the FAFSA (Free Application for Federal Student Aid), which typically opens October 1 for the following school year at StudentAid.gov.

Types of aid

TypeRepay?Examples
GrantsNoFederal Pell Grant, state grants, college grants
ScholarshipsNoMerit, need-based, private/community scholarships
Work-studyNo (you earn it)Part-time campus jobs
Federal loansYesDirect Subsidized/Unsubsidized loans, Parent PLUS
Private loansYesBanks and lenders — usually a last resort

How the FAFSA works

  1. Student and each required contributor (usually parents) create a StudentAid.gov account.
  2. Complete the form; contributors give consent to import federal tax information.
  3. List every college you’re considering (you can add more later).
  4. You’ll receive a FAFSA Submission Summary with your Student Aid Index (SAI) — the number colleges use to calculate need.
  5. Colleges send aid offers after admission.

The CSS Profile

Several hundred mostly private colleges also require the CSS Profile for their own institutional aid. It asks for more detail than the FAFSA. Check each college’s financial aid page.

Comparing aid offers

Line up each offer by net cost = cost of attendance − grants and scholarships. Loans and work-study are not discounts. If an offer seems low, you can appeal with new information (job loss, medical costs, a better offer elsewhere).

Frequently asked questions

When should I file the FAFSA?

As early as possible after it opens (normally October 1). Some state and college aid is first-come, first-served.

Do I need to file the FAFSA if my family earns too much?

Usually yes. Many colleges require it for merit scholarships and it’s the only way to access federal student loans.

What is the Student Aid Index?

The SAI is an eligibility index calculated from your FAFSA. Colleges use it to determine need-based aid. It can be negative (down to −1,500).
